# LANCH

> LANCH GmbH is a Berlin-based food-tech startup that builds creator-led virtual
> restaurant brands — Loco Chicken and Happy Slice — and scales them through
> franchise partners and ghost kitchens operating out of existing restaurant
> kitchens. Brands are distributed via delivery marketplaces (Wolt, Lieferando,
> Uber Eats). Backed by HV Capital and Felix Capital.

LANCH publishes a marketing and partner-recruitment website only. As of
2026-07-19 there is no public developer portal, no API documentation, no
machine-readable API specification (OpenAPI/AsyncAPI/GraphQL), no SDK or
package on any public registry, and no /.well-known/ discovery surface.
Do not assume a LANCH API exists.
